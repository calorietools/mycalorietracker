# mycalorietracker
Calorie tracking website.

> [!NOTE]  
> This project is not intended for real-world use, please do not use it to store your calorie data.
>

## Features 
- Easy to use and fast interface
- Categorizes food by meal type 
- Supports a range of exercise types
- Helpful dashboard gives you information at a glance

## Getting started
1. Ensure that you have docker installed.
2. Download compose.yaml from this repo
3. Run the following command in the same directory as the compose file:

```
docker compose up
```
You should now be able to access the website on port 80. By default the API runs on port 8100 and the db on 5432.
